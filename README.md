# Pywr for VS Code

Build, explore and run [Pywr](https://github.com/pywr/pywr-next) water resource models
without leaving your editor. Pywr models are large JSON files, and this extension turns
them into something you can navigate, edit with forms, draw on a schematic, run with
one click and chart the results of.

The extension works with models for Pywr v2 and for [Pywr v1](https://github.com/pywr/pywr).
It recognises which version a model is written for, and the status bar shows it.

**[Read the documentation](https://s-simoncelli.github.io/pywr-vscode)** for the step by
step guides, from your first model to charting its results.
