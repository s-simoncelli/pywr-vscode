Draw the schematic

The schematic shows the nodes and the edges of your model as a diagram. What you change on it is written to the model file.

Open the schematic

Section titled “Open the schematic”

Use any of these while a model is open:

  • the schematic button at the top right of the editor
  • the schematic button at the top of the Model view
  • Ctrl Alt P, then S

Each node is a circle in the colour of its type, with its name below. A virtual node is a square with a dashed border and its name in italic. There is one schematic for each model, and it updates when the JSON file changes.

Move around

Section titled “Move around”
  • Drag the background to move, and scroll to zoom.
  • Use the buttons on the left to zoom in, zoom out and fit the whole network in the view.
  • The minimap at the bottom right shows where you are in a large network.
  • Hover a node to read its JSON. Hover an edge to see the nodes and the slots it connects; turn this off with the pywr.schematic.showEdgeLabelOnHover setting.

The zoom and the position are remembered for each model. To forget them all, run Pywr: Clear Saved Schematic Zoom & Position.

Move a node

Section titled “Move a node”

Drag a node to its new place. Its position is saved in the model file, so the layout is shared with everyone who opens the model.

Add a node

Section titled “Add a node”

  1. Press Add node in the toolbar at the bottom of the schematic. A panel opens with the types of node.

  2. Drag a type onto the schematic and drop it where the node should be.

  3. Type the name of the node and press Enter.

The node is added to the model with the default values of its type, and its form opens so you can set them. To stop the form opening, turn off the pywr.openFormOnAdd setting.

Connect two nodes

Section titled “Connect two nodes”

  1. Press Add edge in the toolbar. The schematic enters connecting mode and shows the slots of each node: water leaves from a green slot and arrives at a red slot.

  2. Drag from a green slot of the first node to a red slot of the second node.

  3. Add as many edges as you need, then press Exit connecting mode or Esc.

Edit, rename and delete

Section titled “Edit, rename and delete”
  • Double-click a node to open its form.
  • Right-click a node or an edge for Edit, Rename, Find usages, Go to JSON and Delete. Rename and Find usages are for nodes only.
  • Select one or more items, then press Delete item in the toolbar, Delete or Backspace. You are asked to confirm, and told when a node is still used by other components.

Customise the view

Section titled “Customise the view”

The View button in the toolbar opens a panel with the options to change what the schematic shows:

  • Virtual nodes shows or hides the virtual nodes, with the dashed lines to the nodes they refer to.
  • Virtual node lines shows or hides only the dashed lines.
  • Node names shows or hides the names below the nodes.
  • Node size makes the nodes, with their icon and name, smaller or larger.

The two options for the virtual nodes are only listed when the model has virtual nodes.

The options are saved in the settings of the workspace (.vscode/settings.json) or, when no workspace is open, in your user settings. See the pywr.schematic.* settings.

Pywr v1 The virtual nodes are the AggregatedNode and AggregatedStorage nodes, and the nodes whose type is, or contains, VirtualStorage (for example AnnualVirtualStorage or a custom MyVirtualStorage node).

Draw the network on a map

Section titled “Draw the network on a map”

When the nodes of a model have geographic coordinates, the schematic is drawn on a map.

To start a new model on a map:

  1. Open the schematic of a model with no nodes. You are asked how to draw it.

  2. Pick Map.

  3. Type the latitude and the longitude of the area of your model, such as 51.48, -3.18, or leave the field empty to start from a map of the world.

  4. Add your nodes. They are saved with their latitude and longitude.

Note

The map is drawn with tiles from OpenStreetMap, so it needs an internet connection. The rest of the extension works offline.

Pywr v1 models

Section titled “Pywr v1 models”

Pywr v1 The schematic of a Pywr v1 model uses the position saved with each node, in its editor_position or its schematic key, and keeps the node icons and the edge colours saved in the model. When you move a node, its new position is saved in the editor_position key of the node.

Show the results on the network

Section titled “Show the results on the network”

After a run, the schematic can show the results on the nodes and the edges.

  1. Run the model.

  2. Open the schematic and press Results in the toolbar. The results of the last run are loaded; when there is none, you are asked for a results file.

  3. Read the network:

    • Each node shows its value and the attribute it is for.
    • A storage node shows how full it is, with a bar.
    • Pywr v2 Edges get wider as their flow grows, and are dashed when the flow is zero.
    • Pywr v2 When a node saves more than one attribute, pick the one to show from the list on the node.

  4. Use the bar at the top to move through the run:

    • pick the scenario
    • drag the slider to a time step, or press Play to move through them
    • click the file name to show the results of another file
    • press Hide the results to go back to the plain schematic

Run the model live

Section titled “Run the model live”

You can also run the model from the schematic and watch it one time step at a time, without a results file. This helps to find where the network is constrained and when a demand is not met.

  1. Open the schematic and press Run live in the toolbar. The model is saved and loaded with the Python environment selected in the Python extension, and its first time step is simulated.

  2. Use the bar at the top to move through the run:

    • press Simulate the next time step to advance by one time step
    • press Play to simulate the time steps one after the other, and Pause to stop
    • drag the slider to go back to a time step that was already simulated
    • pick the scenario: all the scenarios are simulated together
    • press Start the run again to go back to the first time step
    • press Stop the run to go back to the plain schematic

  3. Read the network:

    • Each node shows its flow, and each storage node its volume and how full it is.
    • A node with an orange outline and the label max has reached its maximum flow (max_flow): the node limits the flow in the network.
    • An output node with a red outline and the label deficit gets less than its maximum flow: its demand is not met. The label has the deficit, which is the flow the node misses to get its maximum flow. An output node that gets its maximum flow has no outline.
    • Pywr v2 Edges get wider as their flow grows, and are dashed when the flow is zero.

A live run does not save any results: the outputs of a Pywr v2 model and the CSV and tables recorders of a Pywr v1 model are not used. To save the results, run the model. A live run uses the model as it is saved and ignores the options of Run the model with options….

Catchments have no outline, as their flow is always the flow they are given. In Pywr v2 models, the outline is shown for the input, link, output, loss link and water treatment works nodes.
