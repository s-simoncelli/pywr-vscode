See your Pywr model as the network it is

Pywr for VS Code turns a long JSON file into a schematic you can draw on, forms you can fill in, a run you can follow and charts you can check. All in the editor, for Pywr v2 and Pywr v1.

Install in VS Code Read the guide

Needs VS Code 1.110 or later. Also on the Visual Studio Marketplace.

draw

Draw the network instead of imagining it

Open the schematic and every node and edge of your model is on the page. What you change on it is written to the model file.

  • Drag nodes, connect them to add edges, drop new ones from the toolbar
  • Nodes with coordinates are drawn on a map
  • Show the results of a run on the network, one time step at a time
Draw the schematic
edit

Fill in a form, not a page of JSON

Click a component to edit all its fields in one place. Saving the form writes the change back into the JSON file.

  • Pick names from lists and files with a file picker
  • Profiles, control curves and bathymetry are charted as you type
  • CSV tables and timeseries are previewed with their columns
Edit with forms
check

Catch mistakes while you type

The model is checked against the Pywr schema as you edit it, and for the mistakes a schema cannot see.

  • A type that does not exist or a missing field is underlined at once
  • So is a name nothing defines, a node with no edges, a list of the wrong length
  • The light bulb offers the closest name, or creates the component
Check the model for mistakes
run

Run the model with one button

Press Run and follow the model time step by time step. Each run saves its results in a new dated folder next to the model.

  • Pywr v2 is built in: you only need a Python environment
  • Pick the solver, the scenarios and the output folder without editing the model
  • See how long each part of the model took
Run the model
chart

Chart the results where you ran them

Open an HDF5 or CSV results file and tick what to plot. No Python and no notebook.

  • Time series, duration curves and percentile bands across scenarios
  • Aggregate by month or year, and read the statistics of each line
  • Compare two runs, then export the chart as PNG or the values as CSV
Chart the results
QA

Check the model still behaves

A QA report is a set of charts you define once and draw again after every change, such as a reservoir against its control curve.

  • Runs a copy of the model and exports only what is on your charts
  • Saved in a file next to the model, to commit and share with it
  • Exports the charts as a PDF document
Build a QA report

Two versions of Pywr, one extension

The extension recognises which version a model is written for and shows it in the status bar. The sidebar, the forms, the schematic and the charts work the same way for both.

Whether you read JSON or not

If you would rather not open the file

You can build and maintain a model from the sidebar, the forms and the schematic, and never write a brace.

  • A form for every node, parameter, table, timeseries and output
  • Search any component by name or by type
  • See what a component uses, and what uses it, before you change it
  • Rename or delete, and every reference follows

If you live in the JSON

The editor knows the components of your model, like it knows the symbols of code.

  • F2 renames a component everywhere it is used
  • F12 goes to a component, Shift F12 lists its usages
  • Names and types complete as you type, and hovering explains them
  • Links above each component open its form or show it on the schematic
install

Install it, then open a model

  1. Install Pywr from the Extensions view of VS Code, or with the button below.
  2. Open the folder with your model, then its JSON file. No model yet? Run Pywr: New model and pick a template.
  3. Open the schematic from the editor toolbar, or press Run.
Install in VS Code Build your first model

Needs VS Code 1.110 or later. To run a model you also need a Python environment with Python 3.10 or later, and pywr 1 installed in it for Pywr v1 models. Charting results needs no Python.
